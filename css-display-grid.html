CSS display: grid - what it does and how to use it


The complete guide to the display: grid CSS property, including what it does, how it compares with display: flex, and how to use it.

Core Definition

What does display: grid do?

Applying display: grid to an element turns it into a CSS Grid container. Its direct children become grid items, and the container controls how they are sized and positioned.

Without display: grid, children follow the normal page layout. With it, they can be arranged in rows and columns.

CSS 
.container {
  display: grid;
}

That is all it takes to create a grid container.

Once display: grid is applied, you can use properties such as grid-template-columns, grid-template-rows, gap, justify-items, align-items, grid-template-areas.

Comparison

display: grid vs display: flex

Neither is better. They solve different layout problems. Grid works in two dimensions, rows and columns. Flexbox works in one dimension at a time.

Most projects use both. Grid is often used for the main layout, while Flexbox handles alignment within individual components.

Most production projects use both - Grid for the layout shell, Flex for alignment within components.

Comparison

display: grid vs display: inline-grid

display: grid creates a block-level grid container that takes up the full width. display: inline-grid creates an inline-level container that sizes to its content.

Use inline-grid when the container needs to sit inline with text or other elements, like a badge or a small widget.

CSS 
.badge {
  display: inline-grid;
}

inline-grid sizes to its content and sits inline with surrounding text.

Tutorial

Your first CSS Grid container

1

Add display: grid

Apply display: grid to a parent element. All children become grid items.

2

Add columns

Set grid-template-columns to define how many columns and how wide they are.

3

Add a gap

Add gap to set the space between items.

4

Control placement

Place items manually with grid-column and grid-row, or use auto-placement.

CSS 
.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 1rem;
}
.item { background: #4F46E5; }

A complete first grid: a container with display: grid, 3 columns, a gap, and 6 items that auto-place themselves.

Troubleshooting

Common display: grid mistakes

1

Wrong element

Applying grid properties to items instead of the container. display: grid goes on the parent, not the children.

2

Not enough columns

Adding display: grid but no columns - items stack in one column. Add grid-template-columns to define the layout.

3

fr vs %

Using percentages with gap. Percentages include the gap in calculations and can cause overflow. Use fr instead.

4

Implicit grid confusion

Placing items beyond defined columns or rows creates implicit tracks that may be very small. Define grid-auto-columns or grid-auto-rows.

FAQ

Frequently asked questions

What does display: grid do in CSS?
display: grid activates the CSS Grid formatting context on an element, turning its direct children into grid items arranged on rows and columns.
What is the difference between display: grid and display:flex?
display: grid is a two-dimensional layout system that controls rows and columns together. display:flex is one-dimensional, aligning items along a single row or column.
When should I use display: inline-grid instead of display: grid?
Use inline-grid when the container should sit inline with text or other elements, like a badge or small widget, instead of spanning the full width.
Why is my display: grid not working?
Check that display: grid is applied to the parent element, not the children, and that grid-template-columns is defined.
Does display: grid work in all browsers?
Yes, display: grid is supported in all modern browsers.
What are grid items?
Grid items are the direct children of an element that has display: grid applied.
