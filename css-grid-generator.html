Shortcuts & Tips

            
    
                
  • Save layout: Ctrl+S saves your current layout.
    • 
                
  • Copy code: Ctrl+K copies whichever tab (CSS, Tailwind, JS, or SCSS) is currently active.
    • 
                
  • Close any modal: press Esc.
    • 
                
  • Reopen this panel: press Shift+? any time.
    • 
                
  • Fast unit entry: type values like 1fr, auto, or 200px directly into Columns/Rows, separated by spaces.
    • 
                
  • Tab through fields: use Tab to jump between Columns, Rows, and Gap without touching the mouse.
    • 
                
  • Live preview: every change updates the grid preview and generated code instantly, no need to click a refresh button.
    • 
                
  • Save your work: give a layout a name and click Save so you can come back to it later.
    • 
                
  • Check your code: paste existing CSS/Tailwind/JS/SCSS into Grid Detective to catch common grid mistakes.
    • 
            

            
Mac users: use Cmd in place of Ctrl for every shortcut above - Cmd+S to save, Cmd+K to copy code.
