The Basics

What is a CSS Grid Generator?

A CSS Grid generator is a visual tool that lets you build CSS Grid layouts by adjusting controls rather than writing code from scratch. You set your columns, rows and gaps, and a live preview shows you the result as you work.

CSS Grid syntax requires trial and error. You write grid-template-columns, save the file, reload the browser, and then adjust and repeat. A generator collapses that cycle: see the change first, copy the code when it is right.

Most CSS Grid generators output only CSS. Gridlock Holmes outputs CSS, Tailwind, JavaScript and SCSS simultaneously - so whatever tech stack your project uses, the code is ready to copy. It is also paired with Grid Detective, a free tool that checks your grid code for errors.

Getting Started

How to use the CSS Grid generator

Four steps from a blank canvas to production-ready grid code.

1

Set columns

Set your columns using the column controls. Choose fr units for flexible sizing, fixed px for set widths, or mix both.

2

Set rows

Set your rows. Use auto to let content define the height, or set fixed heights in px or rem for precise control.

3

Adjust gap and alignment

Set the gap between columns and rows. Adjust horizontal and vertical alignment for grid items. The preview updates with every change.

4

Copy code

Choose your language from the output tabs - CSS, Tailwind, JavaScript or SCSS - and click Copy. The code is clean and ready to paste.

Why Use One
