Classroom Guide

A suggested classroom approach

These steps work for a 60 to 90 minute session. Adjust to suit your class.

  1. 1
    Open the slides - introduce CSS Grid and session goals
  2. 2
    Live demo the CSS generator - demonstrate columns, gaps and alignment on screen
  3. 3
    Run a build challenge - students recreate a common webpage layout (like Holy Grail) using the generator.
  4. 4
    Grid Detective exercise - students fix a broken grid in pairs
  5. 5
    Export the code - students copy their finished grid code into a real project.
  6. 6
    Homework - direct students to /learn/ to continue at their own pace
